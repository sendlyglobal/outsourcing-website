Design a modern, professional corporate website for a software outsourcing 
company specializing in ERP development, mobile app development, web 
development, and custom software systems.

BRAND PERSONALITY
Technical, trustworthy, and outcome-driven — not flashy or "startup-cute." 
The site should feel like it was built by engineers who take delivery 
seriously, aimed at CTOs, IT directors, and founders evaluating vendors.

COLOR PALETTE
- Primary: Deep navy #0B2545 (headers, footer, primary buttons)
- Accent: Teal #0A8A9E (links, icons, secondary CTAs)
- Highlight: Aqua #6FE3D6 (hover states, small accents only)
- Background: Off-white #F7F9FB alternating with pure white per section
- Body text: Charcoal navy #1C2B39
Use only one accent color per element — never mix teal and aqua on the 
same component.

TYPOGRAPHY
- Headings: geometric/grotesque sans-serif (Inter, Sora, or similar), 
  weight 600–700
- Body: Inter or system-ui, regular 400, 16–17px base, 1.6 line height
- Optional monospace (JetBrains Mono) for any code/architecture snippets
- Scale: H1 40–48px / H2 28–32px / H3 20–22px / Body 16–17px

LAYOUT
- 12-column grid, max content width 1200–1280px
- 8px base spacing unit; section padding 80–120px desktop, 48–64px mobile
- Sticky header, max 72px tall, background solidifies on scroll
- Alternate white/light-grey section backgrounds for visual rhythm
- Mobile-first responsive: breakpoints at 640px and 1024px
- One primary CTA per section — never stack competing buttons

PAGES TO DESIGN
1. Home — hero (outcome-focused headline + 2 CTAs), client logo bar, 
   4 service cards (ERP/Mobile/Web/Custom), proof metrics strip, 
   3 featured case study cards, process overview (4–5 steps), 
   industries icon grid, testimonial, final CTA band
2. Service page template (reusable for ERP/Mobile/Web/Custom Systems) — 
   hero, deliverables list, technology logos, delivery process, 
   2 relevant case studies, FAQ accordion, quote-request form
3. Case study page — challenge/approach/result structure with at least 
   one quantified metric, client quote
4. About page — story, company facts, leadership grid, values, careers link
5. Contact/quote page — short form (name, email, company, project type 
   dropdown, budget range, description) plus a calendar-booking alternative

COMPONENTS TO DEFINE
- Buttons: primary (solid navy, pill shape) and secondary (teal outline)
- Cards: service cards, case-study cards (with one large stat), stat blocks
- Navigation: desktop dropdown menus for Services/Industries, mobile 
  full-screen slide-in menu
- Forms: single-column, labels above fields, inline validation
- Icon set: single consistent outline style, 2px stroke, no mixing styles

IMAGERY DIRECTION
No generic handshake/stock photography. Use real team photos, actual 
product/UI screenshots, and custom line-art diagrams for architecture 
and process flows. Diagrams should look genuinely technical, not decorative.

ACCESSIBILITY
Minimum 4.5:1 text contrast, 44×44px minimum tap targets, one H1 per page, 
full alt text, semantic heading hierarchy.

DELIVERABLE
High-fidelity desktop and mobile mockups for Home, one Service page, and 
Contact, plus a component sheet showing buttons, cards, and form states.
